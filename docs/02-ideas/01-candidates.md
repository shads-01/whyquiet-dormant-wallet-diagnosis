## PART B — Assumption audit

Conventional framing: "an MFS app needs better AI features: fraud detection, chatbots, credit scoring, recommendations." That answer neighborhood = fraud classifier on synthetic transactions, generic churn model, LLM chatbot, uplift dashboard. All territory to leave.

### Five alternative formulations

- F1 — The problem is not *detecting* fraud but *responding* in minutes: make the victim's evidence assembly and fund-tracing fast (A16), not the detector better.
- F2 — The unit of account is the household, not the individual: design for shared phones and intra-family money (A8), not for the ideal single owner.
- F3 — Kill the cash-out event, not the cash-out fee: if baki (shop credit) and QR settle without physical cash, the fee problem and the float problem both dissolve (A5, A6).
- F4 — Make scam networks unprofitable at the cash-out geography: dry up where money leaves the system (agents/merchants/hundi), rather than classifying senders (A5, A7).
- F5 — Eliminate complaints instead of resolving them: predict the failure point from interaction telemetry before the ticket exists (A9 literacy, B11).

## PART C — Lens-driven derivation (10 lenses + 3 local lenses)

Each lens answered verbatim as an outsider, then mapped to source-derived candidates (IDs refer to Part D).

1. **First-principles physics** — Irreducible event: value moves when a record changes AND the user's intent is uncorrupted. Everything else (PINs, agents, receipts) is scaffolding. Shortest path: change the record where the intent is expressed — speech at the moment of intent. → *Talk-Pay Zero (D38), Confirm-Echo Validator (D9), Send-by-Say (D30).*
2. **Economics & incentive design** — Agent bears float cost; provider captures fees; merchants capture the informal cash-out upside (A5). Invert: let the party who profits from a cash-out event pay for it — merchant pays agent-equivalent share to become official; employer pays for wallet wages. → *Merchant-Cannibalization Converter (D17), Wage-Split Advisor (D13), Uplift Referee (D33).*
3. **Behavioral science** — Decision moment = the 8 seconds on the confirm screen while a caller talks. Change only timing/framing: risk-scaled read-back, forced echo. → *Assisted-Send Detector (D3), Scam SMS Verdict (D1).*
4. **Software & automation** — Dispute filing is coordination masquerading as labor; marginal cost of a dossier instance ≈ 0. → *Refund Dossier Automator (D5).*
5. **Manufacturing & process** — WIP sits idle in agent cash replenishment queues and KYC queues; takt = daily float cycle. Only-buy-one-thing: predict demand so float arrives before the queue. → *Agent Float Pre-Positioning (D16), KYC Drop-Off Predictor (D25).*
6. **Evolutionary systems** — Scam tactics evolve under selection pressure (victim conversion); detectors must be scored against variant generations, not static sets. → *Scam Attention Nowcast (D7), Scam Number Prophet (D24).*
7. **Ecology** — Ignored feedback loop: merchant informal cash-out drains agent commission → agents exit → access deserts → more informal workarounds. Keystone: agent economics. → *Merchant-Cannibalization Converter (D17), Agent Trust Scorecard (D29).*
8. **Military & logistics** — Supply line = physical cash to agent points; vulnerable node = liquidity on salary/festival days. Win by positioning and tempo, not force. → *Agent Float Pre-Positioning (D16), Liquidity Weather Map (merged into D16).*
9. **Marketplace & network effects** — Asset is shared corpus + route density: a scam census improves per-user as users join; an agent map improves per-merchant. → *Community Blocklist Co-op (D28), Inclusion White-Space Report (D34).*
10. **Adjacent industries** — India's UPI123Pay (voice payments for feature phones), M-Pesa agent float line-of-credit, parcel industry's click-and-collect. Mechanism, not vibe: offload the transaction leg to a channel with zero marginal UI cost (voice). → *Dialect Hotline Triage (D21), Talk-Pay Zero (D38).*
11. **Historical analogy** — Hundi worked for centuries on trust networks; it failed to digitize because trust couldn't be verified cheaply. That cost just collapsed (speaker verification, NER matching). → *Dialect-Tolerant Anti-Spoof (D4), Consent-Chain Voice (D31).*
12. **Extreme environments** — Disaster cash programming (WFP) proves what's load-bearing at 1000×: offline-verifiable identity, price-aware transfer sizing. → *Bazar Price Oracle (D14), Price-Shock Early Warning (D23).*
13. **Inversion** — Guarantee the worst outcome: freeze accounts randomly, reject dialect speakers' voice, price cash-out highest on payday. Stop doing those things. → *Fair-Freeze Auditor (D11), Handwriting Fairness Audit (D27), Dialect WER Map (D20).*
14. **Information theory** — Signal destroyed: screenshots destroy provenance; recycled numbers destroy identity continuity; Banglish destroys entity resolution. Recover the destroyed signal. → *Proof-Demand Detector (D19), Recycled-SIM Risk (D26), Recipient-NER Matcher (D18).*
15. **Insurance & risk pricing** — Who should hold fraud risk: whoever can diversify it (provider/pool), priced on behaviour. → *Fraud-Buffer Pool (D40, regulatory-risk-marked).*
16. **Game theory** — Attacker's dominant strategy: reuse cash-out mules and pressure scripts. Break the shared resource. → *Community Blocklist Co-op (D28), Agent Scam Drill (D37).*
17. **Public health** — Treat scams epidemiologically: surveillance (census), contact tracing (number clusters), vaccination (drills), not just treatment per victim. → *Scam SMS Verdict (D1), Kill-Chain Screenshot Reader (D2), Agent Scam Drill (D37).*
